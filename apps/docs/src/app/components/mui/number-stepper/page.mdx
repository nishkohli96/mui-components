# MUINumberStepper

<AvailabilityBanner componentName="MUINumberStepper" version="2.2" />

`MUINumberStepper` is [MUINumberInput](/components/mui/number-input) with
always-visible `-` / `+` buttons flanking the input instead of the native
browser steppers. Every numeric behaviour — `number | null` value,
`onlyIntegers`, `nonNegative`, `maxDecimalPlaces`, `stepAmount`, `min` / `max`
clamping, validation and labelling is delegated to `MUINumberInput`. This
component only adds the buttons and disables the decrement / increment button
once its `min` / `max` bound is reached.

`caption` renders custom content (text, an icon, or both) just below the
value — e.g. a unit label like "kg" or "Degrees". `captionProps` styles the
`Box` wrapping `caption` — its `sx` is merged with the component's own base
caption styles (position, spacing, font size, color) rather than replacing
them.

## Usage

```tsx
import MUINumberStepper, { MUINumberStepperProps } from '@nish1896/mui-components/mui/number-stepper';
```

```tsx
const [quantity, setQuantity] = useState<number | null>(1);

<MUINumberStepper
  fieldName="quantity"
  value={quantity}
  onValueChange={({ newValue }) => setQuantity(newValue)}
  onlyIntegers
  min={1}
  max={10}
/>
```

### Customizing icons

- `decrementIcon` / `incrementIcon` — replace the default `-` / `+` icons.
- `swapButtons` — swap the button positions and behaviour, so the increment
  (`+`) button sits on the left of the input and the decrement (`-`) button on
  the right.
- `iconButtonProps` — forwarded to both stepper
  [IconButton](https://mui.com/material-ui/api/icon-button/)s (e.g. `size`,
  `sx`). Interaction and accessibility props are managed by the component.

```tsx
import RemoveCircleOutlineIcon from '@mui/icons-material/RemoveCircleOutline';
import AddCircleOutlineIcon from '@mui/icons-material/AddCircleOutline';

<MUINumberStepper
  fieldName="temperature"
  value={temp}
  onValueChange={({ newValue }) => setTemp(newValue)}
  decrementIcon={<RemoveCircleOutlineIcon />}
  incrementIcon={<AddCircleOutlineIcon />}
  iconButtonProps={{ size: 'medium', sx: { color: 'primary.main' } }}
/>
```

### Adding a caption

`caption` renders content just below the value, centered between the two
buttons. It accepts any `ReactNode` — text, an icon, or both — which makes it a
good fit for a unit label:

```tsx
<MUINumberStepper
  fieldName="weight"
  value={weight}
  onValueChange={({ newValue }) => setWeight(newValue)}
  nonNegative
  min={1}
  caption="kg"
/>
```

For an icon with text, pass both as the caption. The caption is a flex
container, so the two sit side by side and are vertically centered:

```tsx
import DeviceThermostatIcon from '@mui/icons-material/DeviceThermostat';

<MUINumberStepper
  fieldName="temperature"
  value={temp}
  onValueChange={({ newValue }) => setTemp(newValue)}
  caption={(
    <>
      <DeviceThermostatIcon sx={{ fontSize: 14 }} />
      <span>°C</span>
    </>
  )}
/>
```

A falsy `caption` (`undefined`, `null`, `''` or `0`) renders nothing. While a
caption is shown, the input's vertical padding is reduced so the value and
caption sit close together.

### Styling the caption

`captionProps` is forwarded to the `Box` that wraps `caption` — any
[Box](https://mui.com/material-ui/api/box/) prop except `children`, such as
`sx`, `className` or `data-*` attributes. Its `sx` is merged with the caption's
base styles instead of replacing them, so you only list what you want to change.
The base styles are:

| Style | Default |
|---|---|
| `display` / `alignItems` / `alignSelf` | `flex` / `center` / `center` |
| `fontSize` | `11` |
| `lineHeight` | `1` |
| `color` | `text.secondary` |
| `whiteSpace` | `nowrap` |

`sx` can be an object, an array or a function:

```tsx
<MUINumberStepper
  fieldName="targetTemp"
  value={targetTemp}
  onValueChange={({ newValue }) => setTargetTemp(newValue)}
  caption="°C"
  captionProps={{
    sx: {
      fontSize: 12,
      fontWeight: 700,
      color: 'primary.main'
    }
  }}
/>
```

`captionProps` has no effect when `caption` isn't provided.

## API

`MUINumberStepperProps` extends
[MUINumberInputProps](/components/mui/number-input#api) (minus `showMarkers`)
and also accepts most
[TextFieldProps](https://mui.com/material-ui/api/text-field/), with some props
excluded, including `type`, `multiline` and `rows`.

Props marked with <strong
style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
