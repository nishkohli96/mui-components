# MUINumberStepper

`MUINumberStepper` is [MUINumberInput](/components/mui/number-input) with
always-visible `-` / `+` buttons flanking the input instead of the native
browser steppers. Every numeric behaviour - `number | null` value,
`onlyIntegers`, `nonNegative`, `maxDecimalPlaces`, `stepAmount`, `min` / `max`
clamping, validation and labelling, is delegated to `MUINumberInput`. This
component only adds the buttons and disables the decrement / increment button
once its `min` / `max` bound is reached.

## Usage

```tsx
import MUINumberStepper, { MUINumberStepperProps } from '@nish1896/mui-components/mui/number-stepper';
```

```tsx
const [quantity, setQuantity] = useState<number | null>(1);

<MUINumberStepper
  fieldName="quantity"
  value={quantity}
  onValueChange={({ newValue }) => setQuantity(newValue)}
  onlyIntegers
  min={1}
  max={10}
/>
```

## API

`MUINumberStepperProps` extends [MUINumberInputProps](/components/mui/number-input#api)
(minus `showMarkers`) and also accepts the remaining
[TextFieldProps](https://v7.mui.com/material-ui/api/text-field/), except `type`,
`multiline` and `rows`. Props marked with
<strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
