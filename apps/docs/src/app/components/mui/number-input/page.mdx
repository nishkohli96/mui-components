# MUINumberInput

`MUINumberInput` is a [TextField](https://mui.com/material-ui/react-text-field/)-based numeric input that enforces number-only entry with options for integers-only, non-negative values, a maximum number of decimal places, and keyboard step increments.

## Usage

```tsx
import MUINumberInput from '@nish1896/mui-components/mui/number-input';
```

```tsx
const [age, setAge] = useState<number | null>(null);

<MUINumberInput
  fieldName="age"
  value={age}
  onValueChange={({ newValue }) => setAge(newValue)}
  onlyIntegers
  nonNegative
/>
```
