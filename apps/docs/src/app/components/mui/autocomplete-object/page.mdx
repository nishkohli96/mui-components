# MUIAutocompleteObject

`MUIAutocompleteObject` is an [Autocomplete](https://v7.mui.com/material-ui/react-autocomplete/) that stores the **complete option object** rather than a primitive.

<Callout type="note">
  `freeSolo` is intentionally unsupported to keep the value type predictable — use `MUIAutocomplete` for that.
</Callout>

## Usage

```tsx
import MUIAutocompleteObject from '@nish1896/mui-components/mui/autocomplete-object';
```

```tsx
const [user, setUser] = useState<User | null>(null);

<MUIAutocompleteObject
  fieldName="user"
  value={user}
  onValueChange={({ newValue }) => setUser(newValue)}
  options={users}
  labelKey="name"
  valueKey="id"
/>
```

## Props

`labelKey` and `valueKey` are required. `MUIAutocompleteObjectProps` also accepts most [AutocompleteProps](https://v7.mui.com/material-ui/api/autocomplete/). Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
