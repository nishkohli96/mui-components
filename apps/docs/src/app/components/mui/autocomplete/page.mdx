# MUIAutocomplete

`MUIAutocomplete` wraps the Material UI [Autocomplete](https://v7.mui.com/material-ui/react-autocomplete/) and stores **primitive** values (the option string, or the `valueKey` property for object options). It supports single or multiple selection, `disableClearable` and `freeSolo`.

## Usage

```tsx
import MUIAutocomplete from '@nish1896/mui-components/mui/autocomplete';
```

```tsx
const [color, setColor] = useState<string | null>(null);

<MUIAutocomplete
  fieldName="color"
  value={color}
  onValueChange={({ newValue }) => setColor(newValue)}
  options={['Red', 'Green', 'Blue']}
/>
```

## Props

`MUIAutocompleteProps` also accepts most [AutocompleteProps](https://v7.mui.com/material-ui/api/autocomplete/). Use `MUIAutocompleteObject` when you need to store the full option object. Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
