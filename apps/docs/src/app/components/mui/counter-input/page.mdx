# MUICounterInput

<AvailabilityBanner componentName="MUICounterInput" version="2.2" />

`MUICounterInput` is [MUINumberInput](/components/mui/number-input) with
always-visible `-` / `+` buttons flanking the input instead of the native
browser steppers. Every numeric behaviour — `number | null` value,
`onlyIntegers`, `nonNegative`, `maxDecimalPlaces`, `stepAmount`, `min` / `max`
clamping, validation and labelling — is delegated to `MUINumberInput`; this
component only adds the buttons and disables the decrement / increment button
once its `min` / `max` bound is reached.

## Usage

```tsx
import MUICounterInput, { MUICounterInputProps } from '@nish1896/mui-components/mui/counter-input';
```

```tsx
const [quantity, setQuantity] = useState<number | null>(1);

<MUICounterInput
  fieldName="quantity"
  value={quantity}
  onValueChange={({ newValue }) => setQuantity(newValue)}
  onlyIntegers
  min={1}
  max={10}
/>
```

### Swapped icons

```tsx
<MUICounterInput
  fieldName="temperature"
  value={temp}
  onValueChange={({ newValue }) => setTemp(newValue)}
  swapIcons
/>
```

## API

`MUICounterInputProps` extends [MUINumberInputProps](/components/mui/number-input#api)
(minus `showMarkers`) and also accepts most
[TextFieldProps](https://mui.com/material-ui/api/text-field/), with some props
excluded, including `type`, `multiline` and `rows`.

Props marked with
<strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
