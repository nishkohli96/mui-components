# MUIMultiAutocomplete

`MUIMultiAutocomplete` is a multi-select [Autocomplete](https://v7.mui.com/material-ui/react-autocomplete/)
rendering each option with a checkbox and an optional "**Select All**" row. It stores an array of **string**
values. Use `MUIMultiAutocompleteObject` when you need to store full option objects.

<Callout type="note">
  Even though `freeSolo` prop is supported, but is not compatible with `selectAllText`
  and will hide the "**Select All**" option.
</Callout>

## Usage

```tsx
import MUIMultiAutocomplete from '@nish1896/mui-components/mui/multi-autocomplete';
```

```tsx
const [skills, setSkills] = useState<string[]>([]);

<MUIMultiAutocomplete
  fieldName="skills"
  value={skills}
  onValueChange={({ newValue }) => setSkills(newValue)}
  options={['React', 'Vue', 'Angular', 'Svelte']}
/>
```
