# MUIFileUploader

`MUIFileUploader` is a controlled file input with optional drag-and-drop, type/size/count validation, pre-existing server files, and full control over how each file row and the upload button are rendered.

## Usage

```tsx
import MUIFileUploader from '@nish1896/mui-components/mui/file-uploader';
```

```tsx
const [files, setFiles] = useState<File[] | null>(null);

<MUIFileUploader
  fieldName="documents"
  value={files}
  onValueChange={({ newValue }) => setFiles(newValue as File[])}
  accept=".pdf"
  multiple
  maxFiles={3}
/>
```
