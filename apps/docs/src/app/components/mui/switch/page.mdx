# MUISwitch

`MUISwitch` is a single [Switch](https://v7.mui.com/material-ui/react-switch/) with a boolean value, an inline label, and optional helper text or error state.

## Usage

```tsx
import MUISwitch from '@nish1896/mui-components/mui/switch';
```

```tsx
const [enabled, setEnabled] = useState(false);

<MUISwitch
  fieldName="notifications"
  value={enabled}
  onValueChange={({ newValue }) => setEnabled(newValue)}
  label="Email notifications"
/>
```
