# MUINativeSelect

`MUINativeSelect` wraps the Material UI [Native Select](https://v7.mui.com/material-ui/react-select/#native-select) — a real `<select>` element, ideal for mobile and lightweight dropdowns — with the same label/error/helper-text handling as the rest of the suite.

## Usage

```tsx
import MUINativeSelect, { MUINativeSelectProps } from '@nish1896/mui-components/mui/native-select';
```

```tsx
const [country, setCountry] = useState('');

<MUINativeSelect
  fieldName="country"
  value={country}
  onValueChange={({ newValue }) => setCountry(newValue)}
  options={['India', 'United States', 'Germany']}
/>
```

<Callout type="warning">
  When using an array of objects for options, both `labelKey` and `valueKey` 
  are required. If either is missing, an error will be thrown.
</Callout>

## Props

For object options, pass `labelKey` and `valueKey`. Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
