# MUINativeSelect

`MUINativeSelect` wraps the Material UI [Native Select](https://mui.com/material-ui/react-select/#native-select) — a real `<select>` element, ideal for mobile and lightweight dropdowns — with the same label/error/helper-text handling as the rest of the suite.

## Usage

```tsx
import MUINativeSelect from '@nish1896/mui-components/mui/native-select';
```

```tsx
const [country, setCountry] = useState('');

<MUINativeSelect
  fieldName="country"
  value={country}
  onValueChange={({ newValue }) => setCountry(newValue)}
  options={['India', 'United States', 'Germany']}
/>
```
