# MUIOTPInput

<AvailabilityBanner componentName="MUIOTPInput" version="2.1" />

`MUIOTPInput` renders a one-time-password field as `length` individual
[TextField](https://mui.com/material-ui/react-text-field/) boxes, one per
character, backed by a single string `value` with no separators.

## Working

`MUIOTPInput` works as follows:

- Typing a character fills the current box and auto-advances focus to the next
  one.
- **Backspace** on an empty box clears the previous box and moves focus back to
  it.
- **Arrow Left / Right** move focus between boxes without changing the value.
- Focusing a box selects its character, so typing replaces it instead of
  appending.
- Pasting a code distributes its characters across the remaining boxes starting
  from the box where the cursor is — paste into the first box to fill the whole
  field.
- By default only digits are accepted; a non-digit keystroke or paste is
  ignored. Set `alphanumeric` to also allow letters.
- `separatorIndexes` renders a `separator` (default `'-'`) after the given
  zero-based indexes.

  **E.g.** `separatorIndexes={[2, 6]}` with `length={10}` renders as
  `*** - **** - ***`.
- There is no inline label. The label is hidden unless `showLabelAboveFormField`
  (or the `allLabelsAboveFields` config) renders it above the boxes; either way
  the accessible name is applied to every box.

## Usage

```tsx
import MUIOTPInput, { MUIOTPInputProps } from '@nish1896/mui-components/mui/otp-input';
```

```tsx
const [code, setCode] = useState('');

<MUIOTPInput
  fieldName="otp"
  value={code}
  onValueChange={({ newValue }) => setCode(newValue)}
/>
```

By default the code is **6** digits long, so the example above renders six
boxes. `value` is a plain string without separators, such as `'123456'`, and is
shorter while the user is still typing.

### Customizing the length

Use the `length` prop to change the number of boxes. One box is rendered per
character:

```tsx
<MUIOTPInput
  fieldName="pin"
  value={pin}
  onValueChange={({ newValue }) => setPin(newValue)}
  length={4}
/>
```

`onValueChange` always receives `length` characters or fewer, so
`newValue.length === length` tells you the code is complete. For example, to
verify it as soon as the last box is filled:

```tsx
<MUIOTPInput
  fieldName="pin"
  value={pin}
  onValueChange={({ newValue }) => {
    setPin(newValue);
    if (newValue.length === 4) {
      verifyPin(newValue);
    }
  }}
  length={4}
/>
```

Keep `value.length` within `length`. A longer `value`, or a smaller `length`, is
cut down to `length` characters on the next `onValueChange`.

### Alphanumeric codes

Only digits are accepted by default, and mobile devices show the numeric
keyboard. Set `alphanumeric` to also accept the letters `A`–`Z` and `a`–`z`:

```tsx
<MUIOTPInput
  fieldName="inviteCode"
  value={code}
  onValueChange={({ newValue }) => setCode(newValue.toUpperCase())}
  length={8}
  alphanumeric
/>
```

The case of the letters is kept as typed, so convert it yourself if your codes
are uppercase, as above. A pasted code is accepted only if **every** character
is allowed. Pasting `w2323s` into a digits-only field is ignored entirely,
instead of being filtered down to `2323`.

### Separator indexes

`separatorIndexes` lists the zero-based indexes of the boxes that a separator is
rendered after. With `length={8}`, `separatorIndexes={[2, 5]}` renders as
`*** - *** - **`: a separator after the 3rd and the 6th box. The default
`separator` is `'-'`, and it accepts any `ReactNode`.

```tsx
<MUIOTPInput
  fieldName="licenseKey"
  value={code}
  onValueChange={({ newValue }) => setCode(newValue)}
  length={8}
  alphanumeric
  separatorIndexes={[2, 5]}
  separator="–"
  textFieldProps={{ size: 'small' }}
/>
```

Separators are only visual. They are hidden from assistive technology and are
never part of `value`, which stays `'ABC1234XYZ'`. They don't count as
characters when pasting either, so paste the code without separators. An index
equal to the last box is ignored, so no separator is rendered after the final
box.

## API

`MUIOTPInput` does not spread arbitrary
[TextFieldProps](https://mui.com/material-ui/api/text-field/) on itself — use
`textFieldProps` to customize every character box. Props marked with <strong
style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
