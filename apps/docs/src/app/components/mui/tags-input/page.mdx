# MUITagsInput

`MUITagsInput` renders a [TextField](https://mui.com/material-ui/react-text-field/) that turns typed or pasted text into chips. Add, delete and paste actions can be intercepted, transformed or blocked, and the visible chip count can be limited when unfocused.

## Usage

```tsx
import MUITagsInput from '@nish1896/mui-components/mui/tags-input';
```

```tsx
const [tags, setTags] = useState<string[]>([]);

<MUITagsInput
  fieldName="tags"
  value={tags}
  onValueChange={({ newValue }) => setTags(newValue)}
  delimiter=","
/>
```

## Props

`MUITagsInputProps` also accepts the remaining [TextFieldProps](https://mui.com/material-ui/api/text-field/) except `value`, `defaultValue`, `multiline` and `rows`. Props marked with * are required.
