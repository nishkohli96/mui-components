# MUIPhoneInput

`MUIPhoneInput` wraps [react-international-phone](https://www.npmjs.com/package/react-international-phone) inside a [TextField](https://v7.mui.com/material-ui/react-text-field/), with a searchable country dropdown. It emits a structured `MUIPhoneInputValue` (`phone`, `country`, `dialCode`, `phoneNo`).

## Usage

```tsx
import MUIPhoneInput from '@nish1896/mui-components/misc/phone-input';
```

```tsx
const [phone, setPhone] = useState<MUIPhoneInputValue | string>('');

<MUIPhoneInput
  fieldName="phone"
  value={phone}
  onValueChange={({ newValue }) => setPhone(newValue)}
/>
```

## Props

`MUIPhoneInputProps` also accepts most [TextFieldProps](https://v7.mui.com/material-ui/api/text-field/) except `value`, `onChange` and `type`. Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
