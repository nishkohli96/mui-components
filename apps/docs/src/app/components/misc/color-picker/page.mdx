# MUIColorPicker

`MUIColorPicker` wraps [react-color-palette](https://www.npmjs.com/package/react-color-palette) with the suite's label/error/helper-text handling. The emitted value format (`hex`, `rgb`, `hsv`, ...) is chosen with `valueKey`.

## Usage

```tsx
import MUIColorPicker from '@nish1896/mui-components/misc/color-picker';
```

```tsx
const [color, setColor] = useState('#1976d2');

<MUIColorPicker
  fieldName="brandColor"
  value={color}
  onValueChange={({ colorValue }) => setColor(colorValue)}
/>
```
