# MUISelect

`MUISelect` wraps the Material UI [Select](https://v7.mui.com/material-ui/react-select/) with label,
error and helper-text handling. It supports single or multiple selection and either primitive or
object options via `labelKey`/`valueKey`.

<Callout type="tip">
  If the number of options **exceeds 20**, consider using [MUIAutocomplete](autocomplete)
  or [MUIMultiAutocomplete](multi-autocomplete) for better searchability, improved keyboard
  navigation, and overall performance.
</Callout>

## Usage

```tsx
import MUISelect, { MUISelectProps } from '@nish1896/mui-components/mui/select';
```

```tsx
const [role, setRole] = useState();

<MUISelect
  fieldName="role"
  options={['Admin', 'Editor', 'Viewer']}
  value={role}
  onValueChange={({ newValue }) => setRole(newValue)}
/>
```

To select more than one option, set the `multiple` prop to `true`. `value`
and `newValue` then become arrays, and `undefined`, `null`, `''` and `[]`
all mean no selection.

With primitive options, the selected value has the same type as the options,
so a string option gives a `string` and a number option gives a `number`.

`onValueChange` receives `{ newValue, event, child }`: the normalized value,
the Material UI change event, and the selected option element.

### With an array of objects

When `options` is an array of objects,  both `labelKey` and `valueKey`
**are required**.

- `labelKey`: the property used as each option's visible label.
- `valueKey`: the property used as each option's value.

The selected value has the type of the `valueKey` property: a string property gives
a `string`, and a number property gives a `number`.

For example:

```jsx
<MUISelect
  fieldName="country"
  options={[
    { code: 'AUS', country: 'Australia' },
    { code: 'IN', country: 'India' },
    { code: 'UAE', country: 'United Arab Emirates' },
  ]}
  labelKey="country"
  valueKey="code"
  multiple
/>
```

### Default option & placeholder

Two props help when nothing is selected yet. `showDefaultOption` adds a first
menu item with the value `''`, labelled with `defaultOptionText`, which defaults
to "Select" followed by the label generated from `fieldName`, such as `Select Role`.
Choosing it clears the selection. It is disabled when the field is `required`, so
it can't be picked once a real option is chosen.

`placeholder` is text shown inside the closed field while nothing is selected. Unlike
the default option it isn't a menu item, it is shown faded, and the inline label is
not rendered while it is shown.

```tsx
<MUISelect
  fieldName="role"
  options={['Admin', 'Editor', 'Viewer']}
  value={role}
  onValueChange={({ newValue }) => setRole(newValue)}
  showDefaultOption
  defaultOptionText="No role"
/>

<MUISelect
  fieldName="plan"
  options={['Free', 'Pro', 'Team']}
  value={plan}
  onValueChange={({ newValue }) => setPlan(newValue)}
  placeholder="Choose a plan"
/>
```

### Customizing individual options

`renderOptionLabel` replaces the content of each menu item. It receives the
option and a state object with `disabled` and `selected`, so the label can
react to either.

`getOptionDisabled` receives an option and returns `true` to disable it.

```tsx
<MUISelect
  fieldName="product"
  options={[
    { id: 1, name: 'Keyboard', stock: 12 },
    { id: 2, name: 'Monitor', stock: 0 },
    { id: 3, name: 'Mouse', stock: 4 }
  ]}
  labelKey="name"
  valueKey="id"
  value={product}
  onValueChange={({ newValue }) => setProduct(newValue)}
  renderOptionLabel={(option, { disabled, selected }) => (
    <span
      style={{
        opacity: disabled ? 0.5 : 1,
        fontWeight: selected ? 700 : 400
      }}
    >
      {option.name} ({option.stock} in stock)
    </span>
  )}
  getOptionDisabled={option => option.stock === 0}
/>
```

### Custom selected value

`renderValue` changes what the closed field displays, while `renderOptionLabel`
only changes the menu items. It receives the normalized value, which is an array
when `multiple` is set. By default the selected option's label is shown, and the
labels are joined with `, ` for multiple selection.

```tsx
<MUISelect
  fieldName="tags"
  options={['Bug', 'Feature', 'Docs', 'Chore']}
  value={tags}
  onValueChange={({ newValue }) => setTags(newValue)}
  multiple
  renderValue={selected => (
    selected.length ? `${selected.length} selected` : ''
  )}
/>
```

### Styling the options

`menuItemProps` is forwarded to every [MenuItem](https://v7.mui.com/material-ui/api/menu-item/),
including the default option, which is handy for a shared `dense`, `divider` or `sx`.
`inputLabelProps` is forwarded to the [InputLabel](https://v7.mui.com/material-ui/api/input-label/)
shown inside the field's outline. It has no effect when the field uses a label above
(`showLabelAboveFormField`), `hideLabel`, or a `placeholder` with no value selected.

```tsx
<MUISelect
  fieldName="role"
  options={['Admin', 'Editor', 'Viewer']}
  value={role}
  onValueChange={({ newValue }) => setRole(newValue)}
  menuItemProps={{ dense: true, sx: { fontSize: 14 } }}
  inputLabelProps={{ sx: { fontWeight: 600 } }}
/>
```
