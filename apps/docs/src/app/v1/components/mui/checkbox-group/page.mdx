# MUICheckboxGroup

`MUICheckboxGroup` renders a group of [checkboxes](https://v7.mui.com/material-ui/react-checkbox/) from `options` and stores an array of the selected values. Supports primitive or object options via `labelKey`/`valueKey`.

## Usage

```tsx
import MUICheckboxGroup, {
  MUICheckboxGroupProps
} from '@nish1896/mui-components/mui/checkbox-group';
```

```tsx
const [permissions, setPermissions] = useState<string[]>([]);

<MUICheckboxGroup
  fieldName="permissions"
  options={['Read', 'Write', 'Delete']}
  value={permissions}
  onValueChange={({ newValue }) => setPermissions(newValue)}
/>
```

## Props

For object options, pass `labelKey` and `valueKey`.
Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
