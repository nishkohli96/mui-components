# MUITextArea

<AvailabilityBanner componentName="MUITextArea" version="1.4" />

`MUITextArea` is a multiline Material UI [TextField](https://v7.mui.com/material-ui/react-text-field/)
that wires up the label, error state and helper text for you. It is a controlled component
that works with plain `useState` or any form library able to provide a value and receive changes.

Unless you set `rows`, the field grows with its content. Use `maxChars` to cap the length: typing
stops at the limit and pasted text is cut to fit.

For single-line values, use [MUITextField](/v1/components/mui/textfield) instead.

## Usage

```tsx
import MUITextArea, { MUITextAreaProps } from '@nish1896/mui-components/mui/text-area';
```

Provide `fieldName`, `value` and `onValueChange` to render a fully functional text area:

```tsx
const [bio, setBio] = useState();

<MUITextArea
  fieldName="bio"
  value={bio}
  onValueChange={({ newValue }) => setBio(newValue)}
/>
```

Set `rows` for a fixed height, and `maxChars` to limit the length. Typing past the limit is
ignored, and a pasted text longer than the room left is truncated:

```tsx
<MUITextArea
  fieldName="feedback"
  value={feedback}
  onValueChange={({ newValue }) => setFeedback(newValue)}
  rows={4}
  maxChars={50}
/>
```

Add `showCharLimit` to render a `current/max` counter at the bottom-right inside the field. It
sits in its own strip below the text, so typed content never runs under it:

```tsx
<MUITextArea
  fieldName="bio"
  value={bio}
  onValueChange={({ newValue }) => setBio(newValue)}
  maxChars={150}
  showCharLimit
/>
```

Pass `renderCharLimit` to replace the default `current/max` text with your own node. It receives
the current count and `maxChars`:

```tsx
<MUITextArea
  fieldName="bio"
  value={bio}
  onValueChange={({ newValue }) => setBio(newValue)}
  maxChars={150}
  showCharLimit
  renderCharLimit={(charCount, maxChars) => (
    <Typography variant="caption" color={maxChars - charCount <= 10 ? 'error' : 'text.secondary'}>
      {maxChars - charCount} characters left
    </Typography>
  )}
/>
```

`maxChars` uses the native `maxLength` attribute, which counts UTF-16 code units — an emoji
counts as 2 characters. A `value` you set from code is not truncated.

Validation stays in your hands — derive `errorMessage` from your own state or form
library and the field renders in an error state:

```tsx
<MUITextArea
  fieldName="bio"
  value={bio}
  onValueChange={({ newValue }) => setBio(newValue)}
  onBlur={() => setBioError(validateBio(bio))}
  errorMessage={bioError}
/>
```
