# MUIMultiAutocomplete

`MUIMultiAutocomplete` is a multi-select [Autocomplete](https://mui.com/material-ui/react-autocomplete/) rendering each option with a checkbox and an optional "Select All" row. It stores an array of **primitive** values.

## Usage

```tsx
import MUIMultiAutocomplete from '@nish1896/mui-components/mui/multi-autocomplete';
```

```tsx
const [skills, setSkills] = useState<string[]>([]);

<MUIMultiAutocomplete
  fieldName="skills"
  value={skills}
  onValueChange={({ newValue }) => setSkills(newValue)}
  options={['React', 'Vue', 'Angular', 'Svelte']}
/>
```

## Props

Use `MUIMultiAutocompleteObject` when you need to store full option objects. Props marked with * are required.
