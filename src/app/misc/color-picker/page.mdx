# MUIColorPicker

`MUIColorPicker` wraps [react-color-palette](https://www.npmjs.com/package/react-color-palette) with the suite's
label/error/helper-text handling. The emitted value format (`hex`, `rgb`, `hsv`) is chosen with `valueKey`.

## Playground

Driven by plain React state — `valueKey` (hex / rgb / hsv), `defaultColor`,
`excludeAlpha`, a custom `height`, and using `setColor` to reject a value.
