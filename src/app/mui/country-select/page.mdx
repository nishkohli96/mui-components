# MUICountrySelect

`MUICountrySelect` is an [Autocomplete](https://v7.mui.com/material-ui/react-autocomplete/)
pre-loaded with a list of <MuiLink href={externalLinks.githubRepo.countriesList} target="_blank" rel="noopener noreferrer">250 countries</MuiLink>
(**flag**, **name**, **dial code**, **ISO**). Store the complete `CountryDetails` object,
or a single property via `valueKey`. Pin common choices with `preferredCountries`.

## Playground

Driven by plain React state — a single select with `preferredCountries` and a
flag `renderOptionLabel`, and a multi-select with `limitTags` and `ChipProps`.

<CountrySelectForm />

## Props

Pass `valueKey` (e.g. `iso` or `name`) to store a single country property instead of the full object. Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
