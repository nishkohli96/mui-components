# MUIRadioGroup

`MUIRadioGroup` wraps the Material UI [RadioGroup](https://v7.mui.com/material-ui/react-radio-button/) for a single choice among `options`, storing the selected value. Supports primitive or object options via `labelKey`/`valueKey`.

## Playground

Driven by plain React state — string and object options (`labelKey` / `valueKey`),
`getOptionDisabled`, `radioProps`, a custom `renderOptionLabel`, and required validation.

<RadioGroupForm />

## Props

For object options, pass `labelKey` and `valueKey`. Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
