# MUINativeSelect

`MUINativeSelect` wraps the Material UI [Native Select](https://v7.mui.com/material-ui/react-select/#native-select) — a real `<select>` element, ideal for mobile and lightweight dropdowns — with the same label/error/helper-text handling as the rest of the suite.
