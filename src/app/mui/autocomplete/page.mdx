# MUIAutocomplete

`MUIAutocomplete` wraps the Material UI [Autocomplete](https://v7.mui.com/material-ui/react-autocomplete/)
and stores **primitive** values (the option string, or the `valueKey` property
for object options). It supports single or multiple selection, `disableClearable`
and `freeSolo`.

Use [MUIAutocompleteObject](autocomplete-object) when you need to store the full option object.

## Playground
