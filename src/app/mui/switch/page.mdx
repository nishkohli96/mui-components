# MUISwitch

`MUISwitch` is a single [Switch](https://v7.mui.com/material-ui/react-switch/) with a boolean value, an inline label, and optional helper text or error state.

## Playground

Driven by plain React state — exercises a custom `label`, `formControlLabelProps`
(label placement), pass-through `SwitchProps` (`color` / `size`), `helperText`,
and a required toggle with a custom `renderError` and `customIds`.
