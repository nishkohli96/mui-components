# MUICheckbox

`MUICheckbox` is a single [Checkbox](https://v7.mui.com/material-ui/react-checkbox/)
with a boolean value, an inline label, and optional helper text or error state.

## Playground

Driven by plain React state — a custom `label`, pass-through `CheckboxProps`
(`color` / `size`), `helperText`, and a required checkbox with a custom `renderError`.

## Props

`MUICheckboxProps` also accepts most [CheckboxProps](https://v7.mui.com/material-ui/api/checkbox/).
Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
