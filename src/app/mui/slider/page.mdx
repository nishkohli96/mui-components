# MUISlider

`MUISlider` wraps the Material UI [Slider](https://v7.mui.com/material-ui/react-slider/)
for a single number or a range (number array), with label, error and helper-text handling.

## Playground

Driven by plain React state — a single-value slider, a range slider (number
array), and `SliderProps` (`min`, `max`, `step`, `marks`, `valueLabelDisplay`).

<SliderForm />

## Props

`MUISliderProps` also accepts most [SliderProps](https://v7.mui.com/material-ui/api/slider/).
Pass a number array as `value` for a range slider. Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
