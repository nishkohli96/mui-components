# Changelog - v1

## [1.2.0](https://github.com/nishkohli96/mui-components/tree/v1.2.0)

**Released - 31 August, 2026**

### ⚙️ Project & Tooling
- Docs: replaced the unmaintained `react-json-view` with the actively-maintained `@microlink/react-json-view` fork.

### ✨ Enhancements
- Added `MUIOTPInput` — a controlled one-time-password input rendered as individual `TextField` boxes, backed by a single string value. Supports both numeric and alphanumeric values, and exposes an `inputRef` to the first box for imperative focus (e.g. React Hook Form's `setFocus`).

### 📖 Docs
- Added the `MUIOTPInput` component page, sidebar entry, props reference and a live playground.


## [1.1.4](https://github.com/nishkohli96/mui-components/tree/v1.1.4)

**Released - 28 August, 2026**

### 🐞 Bug Fixes
- `ConfigProvider`: Removed a broken `API:` JSDoc link — `MUIComponentsConfigInput` has no separate `#api` section on the Customization page.
- `fieldNameToId`: Corrected a stale JSDoc example (`"user.name"` → `"user.email"`).
- `MUIFileUploader`: Fixed single-file mode wiping the current value to `null` when a replacement file was rejected (invalid type/size or over `maxFiles`) — the current file is now kept instead.


## [1.1.3](https://github.com/nishkohli96/mui-components/tree/v1.1.3)

**Released - 13 August, 2026**

### ✨ Enhancements
- Added JSDoc summaries (with `Docs`/`API` links) to every `MUI*` component, `DefaultMUIComponentsConfig`, `ConfigProvider`, and `countryList`.

### 📖 Docs
- Renamed the **Props** section to **API** on every component page, so the reference table anchor matches the new `#api` JSDoc links.

### 🐞 Bug Fixes
- `MUIPhoneInput`: The country search field stopped propagation on every keydown, preventing "**Escape**" key from reaching MUI's `Menu` and closing the dropdown; Escape now propagates normally while other keys are still blocked from reaching `Select`.


## [1.1.2](https://github.com/nishkohli96/mui-components/tree/v1.1.2)

**Released - 12 August, 2026**

### ⚙️ Project & Tooling
- Upgraded `tsdown` from `0.22.3` to `0.22.14`.
- Added a `prod` script (`next build && next start`) to `apps/docs`, runnable from the root as `pnpm docs:prod`.

### ✨ Enhancements
- Added JSDoc comments for `fieldNameToId`, `getFileSize` and `validateFileList` functions, exported from the `form-helpers` module.

### 🐞 Bug Fixes
- `getFileSize`: Fixed trailing zeros (e.g. `1.20`) not being stripped from the decimal part.
- `validateFileList`: Fixed `maxSize={0}` and `maxFiles={0}` being treated as "no limit" instead of rejecting all files.


## [1.1.1](https://github.com/nishkohli96/mui-components/tree/v1.1.1)

**Released - 7 August, 2026**

### 📖 Docs
- Remove Stackblitz link from repo and package `README.md` and link `v1-playground` branch on github.

### 🐞 Bug Fixes
- `MUIPhoneInput`
  - Fix country dropdown scrollbar spanning full menu height alongside sticky search field; scroll region now starts below it.
  - Removed `multiple` and `multiline` from `countrySelectProps`; both are always `false`.
  - Fixed a console warning ("out-of-range value") and a brief mispositioned flash when selecting a country while the search filter was active — every country now stays mounted as a `MenuItem` (hidden via CSS instead of removed) so the selected value always has a matching option.


## [1.1.0](https://github.com/nishkohli96/mui-components/tree/v1.1.0)

**Released - 7 August, 2026**

### ⚙️ Project & Tooling
- Upgraded `pnpm` from `11.10.0` to `11.20.0`.

### ✨ Enhancements
- Exposed previously-unreachable internal sub-component props:
  - `MUIPasswordInput`: `iconButtonProps` for the show/hide toggle button.
  - `MUISelect`: `menuItemProps` (every option `MenuItem`) and `inputLabelProps` (the inline `InputLabel`).
  - `MUIAutocomplete`, `MUIAutocompleteObject`, `MUIMultiAutocomplete`, `MUIMultiAutocompleteObject`: `circularProgressProps` for the loading spinner.
  - `MUIPhoneInput`: `countrySelectProps` for the flag/dial-code trigger `Select`, and `searchCountryProps.menuItemProps` for every country `MenuItem`.

### 🐞 Bug Fixes
- `MUINumberInput`: Set `slotProps.htmlInput.step` to `any` (except for `onlyIntegers`) for decimal inputs (was reusing `resolvedStepAmount`), preventing false "stepMismatch" validation errors on values like 23.45.

## [1.0.2](https://github.com/nishkohli96/mui-components/tree/v1.0.2)

**Released - 3 August, 2026**

### ✨ Enhancements
- Added support for passing an external `ref` to the Autocomplete family, enabling control of the underlying `TextField` via `renderInput`.
- Update the `readOnly` prop documentation for `MUIPasswordInput`.
- Removed `console.warn` messages for `MUINumberInput`, `MUISelect` and `MUINativeSelect`.
- `MUIPhoneInput`: Added a divider between the country search field and the country list for clearer visual separation.
- Added `@mui/system` to `peerDependencies`.

### 🐞 Bug Fixes
- Added the `Theme` generic to `SxProps` in `MUIComponentsConfig` for improved type safety and IntelliSense support.
- Fixed `MUINativeSelect` to pass the option state as the second argument to the `renderOptionLabel` callback.
- Fixed the generic type parameter order in `MUICountrySelect` and exported the `CountrySelectValueKey` type.
- Added support for the `aria-required` attribute to `MUIRating` for improved accessibility.
- `MUIPhoneInput`: Fixed the country dropdown shifting/misaligning out of place on narrow viewports (< 440px) by anchoring it to the field itself instead of the flag trigger.
- Hide `PlaygroundButton` for viewport less than 374px to prevent overlapping with wordmark.
- Fixed the docs site header using white text/icon color in light theme, making the terminal (Playground) icon invisible against the light background.
- Docs: Removed the unused `superstruct` dependency.
