# Changelog - v1

## [1.0.2](https://github.com/nishkohli96/mui-components/tree/v1.0.2)

**Released - 3 August, 2026**

### ✨ Enhancements
- Added support for passing an external `ref` to the Autocomplete family, enabling control of the underlying `TextField` via `renderInput`.
- Update the `readOnly` prop documentation for `MUIPasswordInput`.
- Removed `console.warn` messages for `MUINumberInput`, `MUISelect` and `MUINativeSelect`.
- `MUIPhoneInput`: Added a divider between the country search field and the country list for clearer visual separation.

### 🐞 Bug Fixes
- Added the `Theme` generic to `SxProps` in `MUIComponentsConfig` for improved type safety and IntelliSense support.
- Fixed `MUINativeSelect` to pass the option state as the second argument to the `renderOptionLabel` callback.
- Fixed the generic type parameter order in `MUICountrySelect` and exported the `CountrySelectValueKey` type.
- `MUIPhoneInput`: Fixed the country dropdown shifting/misaligning out of place on narrow viewports (< 440px) by anchoring it to the field itself instead of the flag trigger.
- Hide `PlaygroundButton` for viewport less than 374px to prevent overlapping with wordmark.
